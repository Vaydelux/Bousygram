What stays private and what works offline?

Local videos and subtitles use temporary browser blob: URLs. They are never sent to Bousygram or a remote media server. Only the application shell is cached for offline use; videos are not cached or uploaded.

Why don't MKV, Telegram or native LibVLC always work here?

This browser preview uses the device's built-in media decoder. Unsupported containers/codecs cannot be fixed by a theme or Wasm compilation alone. Full TDLib login, Android Media3/LibVLC and Telegram streams remain Android features until a separate secure web implementation is built.
