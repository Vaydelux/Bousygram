# Cast performance

No Cast device benchmark has been collected. There are no measured connection, startup, seek, rebuffer, sender memory, CPU, battery, or network-overhead results.

Measure selection-to-session, media-load-to-first-frame, seek-to-resume, stalls, bytes downloaded but not consumed, cache bytes served, app PSS/native heap, CPU, and battery. Compare cold partial MP4, fully cached MP4, and constrained-bandwidth playback across repeated runs. Record phone model/API, receiver model/firmware, media codec/container/size, Wi-Fi topology, permission state, and sample count. Do not treat SDK compilation or mock tests as playback performance evidence.
